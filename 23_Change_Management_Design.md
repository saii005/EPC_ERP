# 23. Change Management Design

## Overview
Change Management covers scope changes, change control board, impact analysis, and change tracking to prevent scope creep.

## Change Types
- **Clarifications:** Technical questions/clarifications with no scope change
- **Internal Changes:** Company-initiated improvements
- **Client Changes:** Scope changes requested by client
- **External Changes:** Changes due to regulatory or external requirements
- **Emergency Changes:** Urgent changes to respond to issues

## Change Request Process
1. **Identify Need:** Change identified by team member
2. **Create Change Request:** Document change and justification
3. **Impact Analysis:** Assess cost, schedule, scope, quality impacts
4. **Estimation:** Estimate additional cost and schedule
5. **Approval:** Route for required approvals
6. **Authorization:** Change order if client involved
7. **Implementation:** Execute approved changes
8. **Communication:** Notify all affected parties
9. **Closure:** Update records and close change

## Impact Assessment
- **Scope:** What else is affected?
- **Cost:** Additional cost required?
- **Schedule:** Impact on completion date?
- **Quality:** Impact on quality or specifications?
- **Resources:** Additional resources needed?
- **HSE:** Safety or environmental impacts?

## Change Control Board (CCB)
- **Membership:** PM, Finance, Engineering, Quality, HSE
- **Frequency:** Weekly meetings as needed
- **Authority:** Approve/reject changes up to threshold
- **Escalation:** Large changes escalate to Director/Client
- **Documentation:** Minutes and decisions documented

## Change Tracking
- **Change Log:** Database of all changes
- **Status:** Open, approved, rejected, implemented
- **Trend Analysis:** Identify excessive changes
- **Lessons Learned:** Use changes to improve processes

## Scope Creep Prevention
- **Clear Scope Statement:** Define what is/not included
- **Change Control:** Formal process for all changes
- **Client Communication:** Clarify what is not included
- **Change Costing:** Make cost of changes visible
- **Approval:** Require approval before doing work
