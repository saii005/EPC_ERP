# 20. Project Cost Control

## Overview
Project Cost Control covers budgeting, cost tracking, variance analysis, and cost forecasting to manage project profitability.

## Budgeting
- **Cost Breakdown Structure (CBS):** Hierarchical cost structure aligned to WBS
- **Budget Categories:** Labor, material, equipment, subcontracts, overhead
- **Budget Allocation:** Distribute project budget across cost centers
- **Budget Baseline:** Approved budget for performance measurement
- **Budget Amendments:** Formal process for budget changes

## Cost Tracking
- **Committed Costs:** POs issued, contracts signed
- **Actual Costs:** Invoices received, labor timesheets
- **Cost Allocation:** Assign costs to WBS and cost centers
- **Monthly Cost Reports:** Budget vs. actual tracking
- **Cost Drivers:** Identify major cost influences

## Variance Analysis
- **Cost Variance (CV):** Actual - Budget
- **Cost Performance Index (CPI):** Earned Value / Actual Cost
- **Trend Analysis:** Identify cost trends over time
- **Forecast:** Estimate project final cost
- **Hot Spots:** Identify high-variance items

## Cost Control Measures
- **Value Engineering:** Reduce cost without reducing value
- **Vendor Negotiation:** Reduce procurement costs
- **Efficiency Improvement:** Increase productivity to reduce labor
- **Scope Management:** Prevent uncontrolled scope growth
- **Change Order Management:** Control impact of changes

## Monthly Cost Report
- Budget vs. Actual by cost category
- Cost variance and trending
- Cost forecasting to completion
- Profitability analysis
- Cash flow projection
- Issues and recommendations
