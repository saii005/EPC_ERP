# 50. Print Format Design

## Overview
Print format specifications for documents that need to be printed or sent as PDF.

## Print Format Types

### Purchase Orders
- Header: Company logo, PO#, date, vendor details
- Items table: Description, quantity, unit price, total
- Terms: Payment terms, delivery conditions
- Footer: Signature line, legal terms

### Invoices
- Header: Company logo, invoice#, date, client details
- Items: Description, quantity, rate, amount
- Summary: Subtotal, taxes, total amount due
- Payment terms and bank details
- Footer: Invoice terms, payment instructions

### Daily Progress Report
- Header: Project name, date, location
- Summary: Work summary, crew size, hours
- Activities: List of activities completed
- Materials: Materials received and used
- Issues: Any delays or issues
- Sign-off: Supervisor signature

### Non-Conformance Report
- Header: NCR#, date, project
- Issue description and location
- Severity level
- Root cause analysis
- Corrective actions
- Verification results
- Sign-offs by investigator and approver

### Inspection Report
- Header: ITP#, inspection point, date
- Inspection criteria and acceptance limits
- Inspection results and measurements
- Pass/fail status
- Inspector signature
- Date

### Commissioning Report
- Project name and completion date
- Equipment list with serial numbers
- Test results and performance data
- Training completion
- Punch list closure
- Client sign-off

## Print Format Features
- **Logo:** Company branding at top
- **Header:** Document type, ID, date, parties
- **Tables:** Line items with totals
- **Signature Lines:** Spaces for handwritten signatures
- **Legal Terms:** Contractual language
- **Color:** Professional color scheme
- **Fonts:** Easy to read, scalable

## Export Formats
- **PDF:** For email, archival, signing
- **Excel:** For analysis, data entry
- **CSV:** For data import to other systems

## Paper Size
- **A4:** Standard letter size (210x297mm)
- **Letter:** US standard (8.5x11")
- **Landscape:** For wide tables/gantt charts
