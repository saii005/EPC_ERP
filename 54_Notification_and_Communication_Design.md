# 54. Notification and Communication Design

## Overview
Design for system-triggered notifications (email, in-app, SMS) and user communication.

## Notification Channels
- **In-App:** System inbox and notifications bell.
- **Email:** Standard system notifications (PO, Approval requests).
- **Mobile Push:** Alerts for field personnel.

## Notification Triggers
- **PO Issued:** Notify vendor.
- **Approval Requested:** Notify approver.
- **Inspection Hold Point:** Notify inspector.
- **Incident Reported:** Notify safety officer.
- **Task Overdue:** Notify PM.

## Communication Templates
- HTML/Text templates for automated emails.
- Standardized templates for project communications.
