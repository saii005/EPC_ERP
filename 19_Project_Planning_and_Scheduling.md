# 19. Project Planning and Scheduling

## Overview
Project Planning & Scheduling covers project schedule development, resource allocation, schedule control, and earned value management for cost/schedule control.

## Planning Components
- **Work Breakdown Structure (WBS):** Hierarchical decomposition of project scope
- **Master Schedule:** Project-level schedule with phases and milestones
- **Detail Schedules:** Phase-level and activity-level schedules
- **Resource Allocation:** Assign resources to activities
- **Critical Path Analysis:** Identify activities that determine finish date
- **Schedule Baseline:** Approved schedule for performance measurement

## Scheduling Techniques
- **Network Analysis:** CPM (Critical Path Method)
- **Dependency Logic:** FS (Finish-Start), SS (Start-Start), FF, SF
- **Resource Leveling:** Resolve resource conflicts
- **What-If Analysis:** Scenario planning for delays/acceleration
- **Schedule Forecasting:** Predict completion based on actuals

## Schedule Control
- **Progress Tracking:** Actual progress vs. planned
- **Variance Analysis:** Schedule performance index (SPI)
- **Trending:** Identify schedule trends
- **Forecasting:** Estimate final completion date
- **Corrective Actions:** Address schedule delays
- **Schedule Updates:** Monthly updates with actuals

## Earned Value Management
- **Planned Value (PV):** Budgeted cost of scheduled work
- **Earned Value (EV):** Budgeted cost of work performed
- **Actual Cost (AC):** Actual cost of work performed
- **Schedule Performance Index (SPI):** EV / PV
- **Cost Performance Index (CPI):** EV / AC
- **Forecast:** Project final cost and schedule

## Milestones
- Design complete
- Long-lead PO issuance
- Mechanical complete
- Electrical complete
- Installation complete
- Commissioning complete
- Handover
